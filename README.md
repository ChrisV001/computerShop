# ComputerShop

ComputerShop is a full-stack application that showcases a variety of computers and accessories available for sale. It has functionality for products and integrates a modern frontend and backend architecture.

## Table of Contents
- [Overview](#overview)
- [Installation & Setup](#installation--setup)
- [Running Locally](#running-locally)
- [Additional Resources](#additional-resources)

## Overview
- **Frontend**: Built with **React**, providing a dynamic and responsive user interface.
- **Backend**: Developed with **Node.js** and **Express** to create a robust RESTful API.
- **Database**: Uses **MongoDB** for storing product information and managing data persistently.

## Installation & Setup

1. **Clone the Repository**  
   Make sure to clone the repository:
   ```bash
   git clone https://github.com/ChrisV001/computerShop.git
   cd computerShop

2. **Install Dependencies for Both Frontend and Backend**

   Frontend:
   ```bash
   cd client
   npm install
   ```
   Backend:
   ```bash
   cd ../server
   npm install
   ```

## Running Locally

### 1. Start the Backend

- Open a terminal and navigate to the `api` folder:

   ```bash
   npm start
   ```
### 2. Start the Frontend

- Open a terminal and navigate to the `client` folder:

  ```bash
   npm start
   ```
